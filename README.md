# Nombre del Proyecto
GitFlowPractice
## Descripción
Es un taller para aprender a hacer gitflow.
## Instalación
1. Ve al repositorio del docente en github
2. Utiliza el acceso directo "Use this template", crearás tu propio repositorio
3. Clona el repositorio en tu máquina local: git clone https://github.com/juanmurcia22/GitFlowPractice.git
4. Completa todas las misiones
## Uso
Practica sobre gitflow, este proyecto puedes utilizarlo para probar comandos básicos de git:
Por ejemplo: 
* Ver estado de una rama git status
* Cambiarse a otra rama: git checkout nombreRama
* Crear una rama nueva: git checkout -b nombreRama
* Subir rama al repositorio remoto: git push -u origin rama
